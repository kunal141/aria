# ARIA V3 — Demo Talk Track

> A spoken narrative to use while demoing. Confident, product-focused, executive-
> friendly. No hype, no overclaiming. Private internal demo only.

## Open (15 seconds)

"Most AI tools today are assistants. You ask, they answer. What I want to show you is
something different — an AI *employee* system.

This is the difference between an AI assistant and an AI employee system. An assistant
answers. ARIA owns a goal, plans work, produces artifacts, asks for approval, learns,
and reports value."

## The goal (while showing intake → roadmap → tasks)

"I'm going to give it a real, vague business goal — 'our notification CTR is dropping,
own this.' Notice I'm not writing a prompt. I'm briefing it like I'd brief a person.

It turns that into a problem statement, success criteria, a roadmap, and a task board.
And where it doesn't have enough information, it tells me — it asks instead of guessing."

## The workforce (while showing agents → supervision)

"For the parts that need specialists, it plans a small team of agents — on demand. Then
it supervises them. And here's the honest part: when the evidence isn't there, it
*blocks* and says so. It doesn't fabricate an answer to look productive."

## Learning + improvement (while showing skill proposal → memory lesson)

"It also improves itself — carefully. It noticed it keeps hitting the same gap, so it
*proposes* a new skill. But it can't switch that on by itself; that needs a human and a
safety check.

And it remembers how the work went — reusable lessons, each one citing where it came
from. That's institutional memory, not a chat log."

## Communication + routines (while showing draft → routine)

"It writes the team update a reliable colleague would send. But it's a draft — it can
draft, ask, escalate, and hand off; it cannot send. And it remembers to do recurring
work on a cadence, like a daily review, all locally and deterministically."

## The action gate (while showing preview → dry-run → external blocked)

"Now the part everyone is right to worry about — taking real action. Watch. It previews
the action, runs it dry, and the instant it points at a real external system like
Teams, the gate blocks it. Nothing is sent.

The important part is not autonomy alone. The important part is governed autonomy."

## The dashboard (while showing snapshot + ROI)

"And this is how you manage it — like an employee. One screen: what it worked on, what
it learned, what it needs, what it risks, what's waiting on approval, and the value it
produced. The ROI is clearly marked as an estimate, with the method shown — we don't
invent numbers."

## Where the big runtimes fit (30 seconds)

"People ask, 'doesn't Anthropic's managed agents or launch-your-agent do this?' No — and
that's the point.

Anthropic can provide managed agent runtime. ARIA provides governed work ownership.
launch-your-agent may create agents quickly. ARIA decides which agents should exist,
what they're allowed to do, how they're evaluated, and how their work is remembered.

Those runtimes can *become workers under ARIA* later. They don't replace it. The runtime
is swappable. The governance, memory, audit, and ROI layer is the moat."

## Close (15 seconds)

"Everything you just saw ran offline. Nothing was sent, nothing was written to an
external system, nothing was deployed. It's governed end to end, it's been working
through a full goal start to finish, and it's private until we decide otherwise.

That's ARIA V3 — a governed AI employee workforce."

---

### Delivery notes
- Pause after each "boundary" beat — the blocks and drafts are the *feature*, not a
  limitation. Let them land.
- If asked "is it autonomous?" → "Governed autonomy. It acts only through an approval
  gate, and live execution is off by design."
- If asked "is this live in production / public?" → "No. Private internal pilot. Public
  release is intentionally blocked until we have employer and IP approval."
- Avoid: "fully autonomous", "replaces engineers", "production-ready SaaS", "it can do
  anything." None of those are true and none of them are the pitch.
