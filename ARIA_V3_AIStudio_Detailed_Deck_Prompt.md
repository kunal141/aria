# Recommended Story Arc

The story should flow like this:

1. **Why this matters** — AI tools answer, businesses need work ownership.
2. **What ARIA is** — governed AI employee control plane.
3. **How V3 works** — goal → plan → agents → evidence → approval → learning → dashboard.
4. **Why it is safe** — approval gates, Work Ledger, path confinement, deny-by-default action gate.
5. **Why it is valuable** — reusable work, manager visibility, ROI estimation.
6. **Why it is not replaced by managed agents** — external runtimes are workers; ARIA is the governance/control layer.
7. **What comes next** — V4 roadmap as future, not started.
